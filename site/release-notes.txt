ZgData Toolkit - Novosti i povijest verzija
================================================

Verzija 1.4.0 - SysAdmin Diagnostics Expanded Build
Datum: 19.08.2026.

NOVO - STORAGE / SMART DIAGNOSTICS
- Dodan kompletan Storage / SMART modul u SysAdmin Hub.
- ONE-CLICK DIAGNOSTIC radi disk, volume, event, findings i report snapshot.
- Background monitor prati Disk Active %, read/write MB/s, read/write latency i queue.
- Live prikaz Top process I/O s PID-om i trendom.
- PROBLEM HAPPENED marker sprema stanje u tocnom trenutku incidenta.
- Session Analysis prikazuje average/peak/P95 i sustained pressure te donosi storage bottleneck verdict.
- Diskovi / SMART, volumeni i relevantni storage/NTFS eventi dostupni su u odvojenim tabovima.
- NTFS Event 98 healthy-volume poruke klasificiraju se kao INFO umjesto laznih warninga.
- Action Center: CHKDSK /scan, Storage Event Viewer, Disk Management, Optimize Drives i HTML report.
- Process I/O se ne tretira sam kao dokaz fizickog disk bottlenecka; korelira se s latency/queue/active signalima.

NOVO - WINDOWS REPAIR & HEALTH
- Dodan Windows Repair & Health modul.
- Baseline Windows Update/servicing, service i pending reboot provjera.
- DEEP HEALTH CHECK izvodi DISM /CheckHealth i SFC /verifyonly bez popravaka.
- Live output je unutar Toolkita, bez zasebnog PowerShell prozora.
- Dodan stvarni progress parser za SFC i DISM.
- Component Store i System Files statusi prikazuju rezultat provjere.
- SMART REPAIR NOW prikazuje se samo kada postoji konkretna potreba.
- Smart Repair koristi DISM /RestoreHealth i potrebne provjere uz kontrolirani UAC.
- Kada je sustav zdrav, Toolkit prikazuje NO REPAIR NEEDED i ne pokrece nepotrebne repair korake.
- HTML report i servisni logovi dostupni su iz modula.

NOVO - PERFORMANCE / FULL GAS
- Dodan live Performance / Full Gas modul.
- Prati CPU, RAM, commit pressure, processor queue, paging/hard page reads i process I/O.
- Prikazuje Top CPU, Top RAM i Top I/O procese.
- Reported CPU clock i clock ratio koriste se kao dijagnosticki signal, bez lazne tvrdnje o thermal throttlingu.
- PROBLEM HAPPENED sprema CPU, RAM, commit, clock, queue/paging i vodece procese.
- Session Analysis razlikuje CPU bottleneck, memory pressure, paging pressure, CPU queue pressure, mixed pressure i high process I/O.
- Dodan offender/correlation prikaz i prosireni HTML report.
- Full Gas akcije ostaju kontrolirane i prate prethodni/aktivni power plan.


NOVO - STARTUP / SERVICES DIAGNOSTICS
- Dodan kompletan Startup / Services modul u SysAdmin Hub.
- Inventar startup stavki prikazuje scope, tip, naziv, command/target i lokaciju.
- Servisi se analiziraju s klasifikacijom Microsoft-ish / Third-party te statusom i startup tipom.
- Upozorenja za automatske servise prikazuju se kao alerti, bez automatskog gasenja servisa.
- Scheduled Tasks modul prikazuje zadnji rezultat, sljedeci run, autora i klasifikaciju.
- Alert kartice su klikabilne i vode direktno na filtrirani popis problema.
- Task Scheduler result kodovi se dekodiraju u razumljiv opis i preporucenu akciju.
- Boot telemetry se cita kontrolirano preko UAC-a kada standardni korisnik nema pristup Diagnostics-Performance logu.
- Prikazuje se procijenjeni last boot i stvarni boot impact kada je telemetry dostupan.
- Action Center omogucuje controlled disable/restore pojedine startup stavke uz preporuku da se prije promjene napravi snapshot.
- HTML report sadrzi startup, services, scheduled tasks, boot telemetry, findings i collector status.

SYSADMIN HUB
- STORAGE / SMART je ACTIVE.
- WINDOWS REPAIR je ACTIVE.
- PERFORMANCE / FULL GAS je ACTIVE.
- STARTUP / SERVICES je ACTIVE.
- Postojeci Network & Cloud, Apross Client Monitor, Printer Diagnostics, GDI/USER Limits i System Health ostaju aktivni.

POSTOJECE 1.4.0 FUNKCIONALNOSTI
- Apross Client Monitor + Resource Guard: GDI/USER/handles/Private RAM baseline, peak, delta, quota, trend i incident correlation.
- GDI / USER Limits: ZgData preporuka GDI 20000 / USER 10000, UAC samo za HKLM promjenu.
- Printer Diagnostics & Repair: inventar, dostupnost, queue, safe repair, GDI test print i report.
- System Health: CPU/RAM, uptime, Windows build, sistemski disk, pending reboot i vazni WHEA/storage/crash eventi.
- Apross Regional Settings: hr-HR / Croatia, short date dd.MM.yy, long date dd.MMMM.yyyy, short time HH:mm, long time HH:mm:ss i Croatian system locale.

DISTRIBUCIJA

- Datoteka: ZgDataToolkit-1.4.0-win-x64.zip
- Pokretanje: raspakirajte ZIP i pokrenite ZgDataToolkit.exe.


Verzija 1.3.0 - Printer Diagnostics & Repair
Datum: 13.08.2026.

NOVO - PRINTER DIAGNOSTICS & REPAIR
- Dodan je Printer Diagnostics & Repair modul u ZgData Toolkit.
- Prikazuje instalirane printer queueove, Windows status, port, Host/IP, driver i broj print jobova.
- Provjerava dostupnost mrežnih printera i print/service portove gdje je moguće.
- Razlikuje unavailable/warning stanje i prikazuje razlog dijagnoze.
- Označava moguće stale/duplicate queue kandidate za ručnu provjeru.
- Prikazuje problematične print jobove i omogućuje ručno otkazivanje odabranog joba.
- Dodan je HTML printer report i Action log.
- Dodan je GDI / USER / handles process snapshot.
- Dodan je TEST PRINT :) 01 s velikim 0/1 smileyjem.
- TEST PRINT koristi klasični Windows GDI print pipeline radi bolje kompatibilnosti s printer driverima.

SAFE REPAIR
- Recommended fix isključuje "Let Windows manage my default printer" za trenutnog korisnika.
- Ako je trenutni default printer ispravan, ostavlja ga nepromijenjenim.
- Microsoft Print to PDF postavlja se samo ručno ili kada je postojeći default missing/unavailable.
- Printer queueovi, driveri i print jobovi ne brišu se automatski.

ISPRAVLJENO / DORAĐENO
- Ispravljena PowerShell reserved $Host kolizija u printer skeneru.
- Poboljšan kontrast Printer Diagnostics tablica i kontrola.
- XPS test-print put zamijenjen je klasičnim Windows GDI ispisom nakon provjere kompatibilnosti.
- Dodana zaštita kroz backup/build/rollback hotfix postupak tijekom razvoja.


Verzija 1.2.0 - Apross Client Monitor i SQL korelacija
Datum: 15.07.2026.

NOVO - APROSS CLIENT MONITOR
- Dodan je poseban Apross Client Monitor za lokalno pokrenuti Apross.exe.
- Proces se odabire prema PID-u, Windows korisniku, vremenu pokretanja i naslovu prozora.
- Prate se glavni proces, child procesi, WebView2 i pomoćni report/browser procesi.
- Bilježe se CPU, RAM, private memory, handles, GDI, USER objekti i Responding/Not responding stanje.
- TCP veze povezuju se s konkretnim procesom i PID-om.
- Endpointi se klasificiraju kao SQL, Web/API, file share, file transfer, mail ili ostalo.
- Backend se označava kao This computer, Local/LAN ili Public/cloud.
- Dodan je PROBLEM HAPPENED marker za točno označavanje trenutka zastoja.
- Izrađuju se HTML report i CSV datoteke za procesne uzorke, konekcije i timeline.
- Opcionalni detailed packet trace radi kružnu Windows ETL snimku kada je Toolkit pokrenut kao administrator.

NOVO - SQL LIVE CORRELATION
- Toolkit otvara zasebnu SQL monitoring konekciju.
- Lokalni TCP port Apross procesa povezuje se sa SQL Server sesijom.
- Prikazuju se SPID, SQL login, program name, baza, status, command i trajanje requesta.
- Prikazuju se wait type, wait time i blocking session ID.
- Prikazuju se CPU, logical reads, reads, writes i broj otvorenih transakcija.
- SQL tekst može se opcionalno uključiti.
- Dodan je TEST SQL ACCESS s provjerom potrebnih server-state prava.
- Dodane su SQL Server skripte za provjeru, dodjelu i uklanjanje monitoring prava.
- Razdvojeni su Windows user, Apross application user i SQL monitoring login.
- SQL lozinka se ne sprema u report, CSV, settings.json ni source kod.

ISPRAVLJENO
- Ispravljen je PowerShell SQL connection-string problem DataSource.
- Ispravljena je CS0019 build greška u SQL correlation servisu.
- Uklonjene su dvostruko deklarirane SQL varijable.
- Ispravljeno je pokretanje kada je privremena datoteka lokalnih portova prazna.
- Uklonjena su nullable upozorenja u internet-provider lookup servisu.
