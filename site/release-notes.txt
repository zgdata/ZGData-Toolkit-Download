Verzija 1.4.0 - SysAdmin Hub, Resource Guard, System Health i Regional Settings
Datum: 14.08.2026.

NOVO - SYSADMIN HUB
- Glavni prozor Toolkita proširen je centralnim SysAdmin Hubom.
- Aktivni moduli dostupni su odmah s vrha aplikacije.
- Network & Cloud Diagnostics ostaje glavni mrežni i cloud dijagnostički workflow.
- Glavni prozor se otvara maksimiziran.

NOVO - APROSS RESOURCE GUARD
- Resource Guard je integriran u Apross Client Monitor.
- Prati GDI, USER, handles i Private RAM kroz vrijeme.
- Prikazuje baseline, current, peak, delta, quota i postotak iskorištenja.
- Dodana je trend analiza i statusi OK / Observe / Warning / Critical.
- Prvih 60 sekundi služi za baseline; leak procjena koristi dulje vremensko razdoblje.
- Dodan je graf GDI/USER kretanja kroz vrijeme.
- PROBLEM HAPPENED marker ostaje vidljiv u timelineu i HTML reportu.
- Resource Guard podaci uključeni su u Apross HTML report.
- Private RAM je usklađen između live prikaza i HTML izvještaja.

NOVO - GDI / USER RESOURCE LIMITS
- Prikaz trenutačnih Windows GDI i USER quota vrijednosti.
- Prikaz stvarne GDI/USER potrošnje Apross procesa.
- ZgData Recommended: GDI 20000 / USER 10000.
- RESTORE WINDOWS DEFAULTS vraća 10000 / 10000.
- Toolkit ostaje unelevated; UAC se pokreće samo za helper koji mijenja HKLM.
- USER quota se ne podiže iznad 10000 bez mjerenja koja to opravdavaju.

DORAĐENO - PRINTER DIAGNOSTICS & REPAIR
- Printer Diagnostics ostaje zaseban aktivni modul u SysAdmin Hubu.
- Inventar printera, dostupnost, driveri, portovi i queue podaci.
- Safe Repair za problematičan/default printer workflow.
- Klasični Windows GDI TEST PRINT.
- Veliki IT smiley sastavljen od 0/1 elemenata za test GDI ispisa.

NOVO - SYSTEM HEALTH
- CPU load i model procesora.
- Fizički RAM: ukupno, iskorišteno i dostupno.
- Uptime i vrijeme zadnjeg boota.
- Windows edition, verzija, build i arhitektura.
- Slobodan prostor sistemskog diska.
- Pending reboot detekcija.
- WHEA događaji.
- Disk / NTFS / storage događaji.
- Kernel-Power / BugCheck događaji.
- Application Error / Application Hang događaji.
- Overall health status i pojedinačni health checks.
- Izrada System Health HTML reporta.

NOVO - APROSS REGIONAL SETTINGS
- Provjera regionalnih preduvjeta važnih za Apross.
- Culture: hr-HR.
- Region: Croatia.
- Short date: dd.MM.yy.
- Long date: dd.MMMM.yyyy.
- Short time: HH:mm.
- Long time: HH:mm:ss.
- System locale: Croatian (Croatia) / hr-HR.
- APPLY APROSS SETTINGS prvo postavlja culture/region, a zatim custom date/time formate.
- System locale promjena koristi UAC samo kada je potrebna.

DISTRIBUCIJA
- Self-contained Windows win-x64 paket.
- Datoteka: ZgDataToolkit-1.4.0-win-x64.zip.

Verzija 1.3.0 - Printer Diagnostics & Repair
Datum: 13.08.2026.

NOVO - PRINTER DIAGNOSTICS & REPAIR
- Dodan je Printer Diagnostics & Repair modul u ZgData Toolkit.
- Prikazuje instalirane printer queueove, Windows status, port, Host/IP, driver i broj print jobova.
- Provjerava dostupnost mrežnih printera i print/service portove gdje je moguće.
- Razlikuje unavailable/warning stanje i prikazuje razlog dijagnoze.
- Označava moguće stale/duplicate queue kandidate za ručnu provjeru.
- Prikazuje problematične print jobove i omogućuje ručno otkazivanje odabranog joba.
- Dodan je HTML printer report i Action log.
- Dodan je GDI / USER / handles process snapshot.
- Dodan je TEST PRINT :) 01 s velikim 0/1 smileyjem.
- TEST PRINT koristi klasični Windows GDI print pipeline radi bolje kompatibilnosti s printer driverima.

SAFE REPAIR
- Recommended fix isključuje "Let Windows manage my default printer" za trenutnog korisnika.
- Ako je trenutni default printer ispravan, ostavlja ga nepromijenjenim.
- Microsoft Print to PDF postavlja se samo ručno ili kada je postojeći default missing/unavailable.
- Printer queueovi, driveri i print jobovi ne brišu se automatski.

ISPRAVLJENO / DORAĐENO
- Ispravljena PowerShell reserved $Host kolizija u printer skeneru.
- Poboljšan kontrast Printer Diagnostics tablica i kontrola.
- XPS test-print put zamijenjen je klasičnim Windows GDI ispisom nakon provjere kompatibilnosti.
- Dodana zaštita kroz backup/build/rollback hotfix postupak tijekom razvoja.


Verzija 1.2.0 - Apross Client Monitor i SQL korelacija
Datum: 15.07.2026.

NOVO - APROSS CLIENT MONITOR
- Dodan je poseban Apross Client Monitor za lokalno pokrenuti Apross.exe.
- Proces se odabire prema PID-u, Windows korisniku, vremenu pokretanja i naslovu prozora.
- Prate se glavni proces, child procesi, WebView2 i pomoćni report/browser procesi.
- Bilježe se CPU, RAM, private memory, handles, GDI, USER objekti i Responding/Not responding stanje.
- TCP veze povezuju se s konkretnim procesom i PID-om.
- Endpointi se klasificiraju kao SQL, Web/API, file share, file transfer, mail ili ostalo.
- Backend se označava kao This computer, Local/LAN ili Public/cloud.
- Dodan je PROBLEM HAPPENED marker za točno označavanje trenutka zastoja.
- Izrađuju se HTML report i CSV datoteke za procesne uzorke, konekcije i timeline.
- Opcionalni detailed packet trace radi kružnu Windows ETL snimku kada je Toolkit pokrenut kao administrator.

NOVO - SQL LIVE CORRELATION
- Toolkit otvara zasebnu SQL monitoring konekciju.
- Lokalni TCP port Apross procesa povezuje se sa SQL Server sesijom.
- Prikazuju se SPID, SQL login, program name, baza, status, command i trajanje requesta.
- Prikazuju se wait type, wait time i blocking session ID.
- Prikazuju se CPU, logical reads, reads, writes i broj otvorenih transakcija.
- SQL tekst može se opcionalno uključiti.
- Dodan je TEST SQL ACCESS s provjerom potrebnih server-state prava.
- Dodane su SQL Server skripte za provjeru, dodjelu i uklanjanje monitoring prava.
- Razdvojeni su Windows user, Apross application user i SQL monitoring login.
- SQL lozinka se ne sprema u report, CSV, settings.json ni source kod.

ISPRAVLJENO
- Ispravljen je PowerShell SQL connection-string problem DataSource.
- Ispravljena je CS0019 build greška u SQL correlation servisu.
- Uklonjene su dvostruko deklarirane SQL varijable.
- Ispravljeno je pokretanje kada je privremena datoteka lokalnih portova prazna.
- Uklonjena su nullable upozorenja u internet-provider lookup servisu.
