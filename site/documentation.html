Storage / SMART Diagnostics

Modul je namijenjen situacijama kada se server ili računalo naglo uspori i treba brzo utvrditi zakucava li ga disk, koji proces generira I/O i postoje li storage događaji.

  • ONE-CLICK DIAGNOSTIC radi snapshot diskova, volumena, relevantnih događaja, nalaza i priprema report.
  • BACKGROUND MONITOR prati Disk Active %, read/write MB/s, read/write latency, queue i elapsed.
  • Live Top process I/O s PID-om, read/write/total throughputom i trendom.
  • Timeline uzorci i PROBLEM HAPPENED incident marker.
  • Session Analysis: peak, prosjeci, P95, sustained pressure i zaključak postoji li storage bottleneck.
  • Diskovi / SMART, volumeni i filtrirani storage/NTFS eventi.
  • Event 98 healthy-volume provjere klasificiraju se kao INFO, a ne lažni warning.
  • Action Center: CHKDSK /scan, Storage Event Viewer, Disk Management, Optimize Drives i HTML report.
  • One-click monitoring je adaptivan i može se ostaviti u pozadini dok se rade drugi testovi.
Process I/O sam po sebi nije dokaz fizičkog disk bottlenecka. Modul zaključak temelji i na latency/queue/active-time signalima.

Windows Repair & Health

Kontrolirana Windows servisna dijagnostika i repair akcije bez potrebe da cijeli Toolkit radi elevated.

  • Baseline pregled Windows Update / servicing eventa, servisa i pending reboota.
  • DEEP HEALTH CHECK: DISM /CheckHealth + SFC /verifyonly bez popravaka.
  • Live output unutar Toolkita, bez zasebnog PowerShell prozora.
  • Pravi progress parser za SFC i DISM; prikazuje fazu i postotak u glavnom progress baru.
  • Component Store status: Healthy / Repairable.
  • System Files status: No integrity violations / problem detected.
  • SMART REPAIR NOW pojavljuje se samo kada postoji konkretna potreba.
  • Smart Repair može izvesti DISM /RestoreHealth i zatim potrebne provjere; preskače nepotrebne korake kada je sustav već zdrav.
  • Action Center ima read-only DISM/SFC akcije, logove te potvrđene repair operacije koje koriste UAC samo gdje treba.
  • HTML report i log folder.

Performance / Full Gas

Live dijagnostika za računala i servere koji povremeno postanu spori, uz hvatanje točnog stanja u trenutku kada korisnik prijavi problem.

  • CPU load, RAM used, commit pressure i dostupna commit rezerva.
  • Reported CPU clock i clock ratio kao dijagnostički signal; ne proglašava automatski thermal throttling.
  • Processor Queue Length i hard page reads / paging pressure.
  • Live lista procesa: CPU, RAM, read/write/total I/O, handles, threads i trend.
  • Odvojeni Top CPU, Top RAM i Top I/O offenderi.
  • PROBLEM HAPPENED sprema CPU, RAM, commit, clock, queue/paging i vodeće procese u trenutku incidenta.
  • Session Analysis s peak vrijednostima, udjelom uzoraka pod visokim pritiskom i završnim verdictom.
  • Verdicti razlikuju CPU bottleneck, memory pressure, paging pressure, CPU queue pressure, mixed pressure i visoku process I/O aktivnost.
  • HTML report uključuje sažetak sesije i incident correlation.
  • Full Gas akcije vode evidenciju power plana i ostaju kontrolirane/reverzibilne.

Startup / Services Diagnostics

Modul za dijagnostiku startup stavki, Windows servisa, Scheduled Taskova i boot utjecaja bez naslijepog gasenja servisa.

  • Startup Items: scope, tip, naziv, command/target, lokacija i status.
  • Services: stanje, startup tip, account, path, PID i klasifikacija Microsoft-ish / Third-party.
  • Scheduled Tasks: last run, last result, next run, autor i klasa. Alerti se mogu otvoriti direktno klikom na karticu.
  • Task result decoder: numericki rezultat pretvara u razumljiv opis i preporucenu akciju.
  • Boot telemetry: Diagnostics-Performance podaci citaju se preko kontroliranog UAC-a kada standardni korisnik nema pristup logu.
  • Boot impact: prikazuje stvarni boot duration kada je telemetry dostupan; inace ostaje jasno oznacen kao nedostupan.
  • Controlled changes: pojedina startup stavka moze se privremeno disableati za test i kasnije vratiti. Preporucen je startup snapshot prije promjene.
  • HTML report: ukljucuje startup, services, tasks, boot telemetry, findings, alert status i collector status.
